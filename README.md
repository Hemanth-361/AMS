# 🎓 Admission Management System (AMS)

A desktop-based **Admission Management System** built using **Python (Tkinter)** and **MySQL**, designed to manage student admission records efficiently.  
It includes features like student form entry, data management, Excel/PDF export, and more — all in a simple, user-friendly GUI.

## 🧰 Tech Stack

- 🐍 Python 3.x
- 🖼️ Tkinter (for GUI)
- 🗃️ MySQL (for database)
- 📊 `openpyxl` (for Excel export)
- 📝 `fpdf` (for PDF generation)
